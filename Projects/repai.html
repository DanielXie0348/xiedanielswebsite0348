RepAI

Robotics Embedded C PCB Design STM32 KiCad
GitHub ↗ Demo ↗

Overview

RepAI is a real-time AI workout assistant that uses your webcam to count reps, track exercise stages, and give live feedback — no wearables, no gym equipment required. It runs entirely on-device using computer vision and pose estimation.

How It Works

Every frame from the webcam is passed through YOLOv8's pose estimation model, which detects 17 body keypoints in real time. From those keypoints, joint angles are calculated using vector math — for example, the shoulder, elbow, and wrist points define the elbow angle used to track a curl. Each exercise has its own angle thresholds that define the "up" and "down" stages, and a rep is counted every time the full range of motion is completed.

The system also handles side detection automatically — it compares the visibility confidence of left vs right keypoints and maps whichever side is more visible to the active tracking points. This means it works regardless of which side you're facing the camera from.

Exercises Supported

  • Bicep curls — elbow angle tracking (shoulder → elbow → wrist)
  • Squats — knee angle tracking with stage detection
  • Lateral raises — shoulder abduction angle
  • Overhead press — elbow and shoulder range of motion

Architecture

The codebase is structured around a base ExerciseBase class that handles rep counting, stage tracking, and a 3-second countdown delay before tracking begins. Each exercise inherits from this base and implements its own process() method with custom angle logic. A Flask server was also built to expose the feed over a local network, allowing the output to be viewed in a browser.

What I Learned

Building RepAI taught me how to work with real-time ML inference pipelines and the tradeoffs between model accuracy and frame latency. Getting the angle thresholds right for each exercise required a lot of iteration — small changes had a big impact on false positives. It also pushed me to think carefully about code architecture, keeping each exercise modular and easy to extend.

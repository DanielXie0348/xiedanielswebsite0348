Overview

RepAI is a real-time AI workout assistant built as a mobile-first Progressive Web App. It uses your phone camera to count reps, track exercise stages, record sets, and deliver per-set AI coaching feedback — no wearables, no gym equipment, no App Store required. Install directly from Safari to your home screen and it runs exactly like a native app.

YOLOv8n-pose runs server-side, detecting 17 keypoints per frame. Joint angles computed in real time to track rep stages.

Automatic Rep Counting
Angle thresholds define up/down stages per exercise. A rep only counts when full range of motion completes in order — no half-reps.

How Rep Counting Works

Each frame from the phone camera is JPEG-encoded and sent via POST to the Flask server. YOLOv8 runs inference and returns 17 keypoints — shoulders, elbows, wrists, hips, knees, ankles. The system compares summed confidence scores for left vs right side keypoints and automatically maps the more visible side to the active tracking points, so it works regardless of which way you face the camera.

From those keypoints, joint angles are computed using an arctan2 vector method that always returns the smaller interior angle. Each exercise class defines its own thresholds — for a bicep curl, the elbow angle crossing 160° sets stage to "down", crossing back below 35° increments the counter and sets stage to "up".

Exercises Supported

  • Bicep Curl — elbow flexion (shoulder → elbow → wrist)
  • Squat — knee angle (hip → knee → ankle)
  • Lateral Raise — shoulder abduction (hip → shoulder → elbow)
  • Shoulder Press — overhead extension
  • Push-Up — elbow flexion from side profile
  • Lunge — front knee flexion
  • Tricep Extension — elbow extension overhead
  • Calf Raise — hip/ankle ratio proxy

PWA Architecture

The frontend is a single HTML file served by Flask — no build step, no framework. Four screens (Home, Counter, Sets, Profile) live in the same DOM and transition via opacity. A dark pill bottom nav handles routing. Installable on iOS via Safari's Add to Home Screen — runs fullscreen with no browser chrome.

Camera access on iOS requires HTTPS. ngrok tunnels the local Flask server over a secure URL during development, giving the phone camera permission while keeping the backend running locally with full access to the GPU for YOLO inference.

AI Feedback System

After every saved set, the app fires an async call to Claude's messages API with the exercise name and rep count. A system prompt instructs the model to act as a personal trainer and respond in 1–2 warm, specific sentences with no markdown. The response appears in the set card in the Sets tab while the user is already into their next set.

Muscle Map

The Profile tab features front and back SVG body diagrams drawn entirely in code — no image assets. Each muscle group is a named path element. A mapping object connects each exercise ID to the relevant muscle path IDs. After each saved set, worked muscles are highlighted yellow. The map resets every Monday and weekly state persists in localStorage.

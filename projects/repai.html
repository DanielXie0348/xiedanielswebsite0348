RepAI

Python YOLOv8 OpenCV MediaPipe Flask
GitHub ↗

Overview

RepAI is a real-time AI workout assistant that uses your webcam to count reps, track exercise stages, and provide live feedback on form — no wearables, no gym equipment required. It runs entirely on-device using pose estimation and joint angle analysis.

How It Works

Every frame from the webcam is passed through YOLOv8's pose estimation model, which detects 17 body keypoints in real time at 1280×720. From those keypoints, joint angles are calculated using vector math — the shoulder, elbow, and wrist points define the elbow angle used to track a curl, for example. Each exercise has its own angle thresholds defining the "up" and "down" stages. A rep is counted every time the full range of motion is completed in the correct order — preventing half-reps and out-of-sequence counts from registering.

The system also flags incomplete reps in real time. If the joint angle doesn't reach the full contraction or extension threshold, the stage doesn't advance — giving the user live feedback that the rep wasn't completed with full range of motion.

Main inference loop — YOLOv8 per-frame pose estimation with automatic side detection

Exercises Supported

  • Bicep curls — elbow angle tracking (shoulder → elbow → wrist)
  • Squats — knee angle tracking with stage detection
  • Lateral raises — shoulder abduction angle
  • Overhead press — elbow and shoulder range of motion
Curl tracker — angle thresholds define rep stages and enforce full range of motion

Architecture

The codebase is structured around a base ExerciseBase class that handles rep counting, stage tracking, and a 3-second countdown delay before tracking begins. Each exercise inherits from this base and implements its own process() method with custom angle thresholds. A Flask server exposes the live feed over the local network, allowing the output to be monitored in a browser.

Side detection is handled automatically on every frame — the system compares the summed confidence of left vs right keypoints and maps whichever side is more visible to the active tracking points. This means it works regardless of which way you face the camera.

Joint angle calculation — arctan2 vector method always returns the smaller interior angle

What I Learned

Building RepAI taught me how to work with real-time ML inference pipelines and the tradeoffs between model accuracy and frame latency. Getting the angle thresholds right for each exercise required significant iteration — small changes had a big impact on false positives. It also pushed me to think about code architecture, keeping each exercise modular and independently extensible.

Next Steps — Hardware Integration

The next evolution of RepAI transitions the project from a desktop script into a dedicated embedded system. By offloading the UI and feedback loops to a physical controller, the system moves off the laptop screen and onto the weight rack, providing zero-distraction monitoring during high-intensity sets.

  • Embedded Interface: ESP32-powered control node with a high-contrast OLED display to mirror real-time rep counts and velocity data via low-latency UDP.
  • Haptic & Acoustic Feedback: Integrated buzzer and vibration motor to signal "depth reached" or "set complete" without needing to look at a screen.
  • Edge Compute Migration: Transitioning the Python/YOLOv8 pipeline to an NVIDIA Jetson or Raspberry Pi 5 for a fully standalone, camera-in-a-box form factor.
  • Ruggedized Housing: A custom 3D-printed enclosure featuring physical mounts for instant attachment to any standalone gym equipment.

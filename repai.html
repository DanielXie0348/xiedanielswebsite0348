01 — Project

RepAI

Robotics Embedded C PCB Design STM32 KiCad
GitHub ↗ Demo ↗

Overview

RepAI is a PID-controlled autonomous line follower built entirely from scratch — custom PCB, motor driver circuitry, and STM32-based firmware. The goal was to design a robot that could follow a line path with sub-5mm error at high speed, with no off-the-shelf controller boards.

The Challenge

Designing the hardware and firmware simultaneously meant tight feedback loops between schematic iterations and control tuning. The motor driver needed to handle back-EMF safely while the STM32 ran PID loops fast enough to stay responsive at 1.2 m/s.

What I Built

Schematic capture and PCB layout in KiCad, motor driver selection and thermal analysis, STM32 firmware in embedded C with interrupt-driven encoder feedback, and iterative PID tuning on hardware.

  • Custom 2-layer PCB designed in KiCad, manufactured and assembled
  • STM32F4 firmware in embedded C with interrupt-driven encoder feedback
  • PID loop tuned on hardware — sub-5mm path error at 1.2 m/s
  • Motor driver with back-EMF protection and current limiting

Results

Stable path tracking with sub-5mm error at 1.2 m/s sustained. The system handled sharp corners and varying surface reflectivity without manual retuning.
